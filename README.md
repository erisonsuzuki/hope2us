## Objetivo 

Permitir que a ONG cadastrada possa receber doações de novos equipamentos e gerenciar os itens doados.

## O que fazemos

- Criamos uma plataforma online onde um usuário pode escolher um ou vários itens para doar
- Após a escolha do equipamento, o usuário envia o comprovante de doação
- Através de um ambiente gerencial, o admin aprova o comprovante e confirma a doação
- Conforme as doações são feitas e aprovadas, a quantidade dos itens disponíveis para doação são atualizadas
